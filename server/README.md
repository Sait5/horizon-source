# Сервер аккаунтов Horizon

Регистрация по почте, вход, профиль, устройства, подтверждение номера через Telegram-бота и роль администратора.
Всё бесплатное: Vercel (хостинг), Upstash Redis (база), Telegram (бот), Gmail или Brevo (письма).

Аккаунт в браузере необязателен — сайты работают и без него.

## Что хранится на сервере

Имя, почта, номер телефона (только после подтверждения в Telegram), фото профиля, список устройств.
Пароли — только как scrypt-хеш. Сейф паролей, VPN-ключи, история и вкладки на сервер не попадают.

## Запуск у себя

```
cd server
npm install
node dev.js
```

Без настроек письма не отправляются, а коды печатаются в окне сервера. Браузер подключается так:
`HORIZON_ACCOUNT_API=http://127.0.0.1:8787` перед запуском Horizon.

## Выкладка на Vercel

1. **Бот**: в Telegram откройте @BotFather → `/newbot` → придумайте имя и ник бота (например, `HorizonVerifyBot`). Он выдаст токен.
2. **Проект Vercel** с корневой папкой `server`, в Marketplace подключите бесплатный **Upstash for Redis**
   (переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами).
3. **Переменные окружения** в настройках проекта:

| Переменная | Что это |
| --- | --- |
| `SERVER_SECRET` | любая длинная случайная строка |
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | ещё одна случайная строка |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | почта для писем с кодами. Для Gmail: `smtp.gmail.com`, `465`, ваш адрес и «пароль приложения» из настроек Google |
| `ADMIN_PHONES` / `ADMIN_TELEGRAM` / `ADMIN_EMAILS` | кто администратор: номер телефона, ник в Telegram или почта (через запятую) |

4. Подключить бота к серверу: `node scripts/set-webhook.js https://<проект>.vercel.app` (с `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`).
5. В `package.json` браузера указать `"horizon": { "accountApi": "https://<проект>.vercel.app" }` и пересобрать Horizon.

Администратор видит список аккаунтов, может блокировать их и завершать сеансы. Номер и ник в Telegram
засчитываются только после подтверждения через бота, поэтому стать админом, просто указав чужой номер, нельзя.
