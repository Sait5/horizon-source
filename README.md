# Horizon

Браузер для Windows на движке Chromium (Electron). Всё, что внутри, бесплатное и с открытым кодом.

## Запуск

```
npm install
npm run core     # скачать сетевое ядро sing-box (один раз)
npm start
```

## Что умеет

- **Вкладки, адресная строка, стартовая страница** с плитками сохранённых сайтов.
- **Свой поиск без Google и Яндекса**: при наборе — подсказки сайтов из каталога, сохранённого, истории
  и открытых вкладок (понимает «ютуб», «вк» и текст в неправильной раскладке); «ютуб котики» сразу ищет
  на YouTube; калькулятор. Остальное открывает страницу поиска Horizon: подходящие сайты, статьи
  Википедии и кнопки поиска прямо на YouTube, ВКонтакте, Avito, Ozon и других сайтах.
- **Обычные вещи браузера**: меню правой кнопки, поиск по странице (Ctrl+F), масштаб (Ctrl +/−/0),
  печать (Ctrl+P), вернуть закрытую вкладку (Ctrl+Shift+T), F11, видео во весь экран, загрузки с прогрессом
  (программы .exe перед запуском переспрашивают), блокировка всплывающих окон, пометка «Не защищено» для http.
- **Защита в установленной версии**: cookies сайтов шифруются средствами Windows, запуск чужого кода через
  Horizon и подключение отладчика выключены (Electron Fuses), история и прошлые вкладки зашифрованы.
- **Боковая панель**: сохранённые вкладки (звёздочка в адресной строке), группы вкладок,
  восстановление вкладок прошлого сеанса.
- **Конструктор оформления**: тема панелей, цвет акцента, фон стартовой страницы (градиент, свой цвет
  или своя картинка), затемнение, размытие, скругление углов, что показывать.
- **Подписки с привязкой к устройству**: браузер передаёт случайный номер устройства (x-hwid),
  как это требуют панели Remnawave/Marzban, поэтому приходят все серверы подписки.
- **Horizon VPN** — кнопка «VPN» справа. Ключи добавляются ссылкой, подпиской или QR-кодом
  (из буфера, с экрана или из файла). Поддерживаются VLESS (в том числе Reality), VMess, Trojan,
  Shadowsocks, SOCKS5, Hysteria2 и TUIC. Через VPN идёт только трафик браузера.
  Если связь пропала, сайты не открываются напрямую, а загрузки останавливаются.
  Ключи хранятся зашифрованными средствами Windows.
- **Сейф паролей** — кнопка с замком. Открывается мастер-паролем (или Windows Hello, если он настроен).
  Браузер предлагает сохранить пароль после входа на сайт и подставляет его только на том же сайте.
- **Подтверждение с телефона через 2FAS** — нужно для переноса сейфа, смены мастер-пароля,
  нового кода восстановления. Обычный вход на сайты подтверждать не нужно.
- **Код восстановления** — случайный, выдаётся при создании сейфа; после использования заменяется новым.
- **Перенос на другое устройство** — зашифрованный файл сейфа.

## Автообновление

Файл `.github/workflows/release.yml` на GitHub дважды в неделю подтягивает свежий Electron
(в нём исправления уязвимостей Chromium), собирает установщик, подписывает его и публикует релиз.
Установленный Horizon сам скачивает обновление, проверяет подпись и показывает кнопку «Обновить»;
если её не нажать, обновление встанет при закрытии браузера.

Чтобы это заработало, нужны репозиторий на GitHub и секрет `HORIZON_UPDATE_KEY`
(содержимое `keys/update-private.pem`) в его настройках.

## Выпуск версии вручную

```
npm run update-key   # один раз: ключ подписи обновлений (keys/ — хранить в секрете и в резервной копии)
npm run dist         # установщик dist/Horizon-Setup-<версия>.exe
npm run release      # подпись: dist/latest.json
```

Установщик и `latest.json` загружаются в релиз GitHub. Репозиторий указывается в `package.json` → `horizon.updateRepo`.
Браузер скачивает обновление и запускает его, только если подпись совпала с ключом, встроенным в программу.
